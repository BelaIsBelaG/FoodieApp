## Descripción general de la aplicación

FoodieApp es una aplicación móvil desarrollada para permitir a los usuarios explorar diferentes tipos de comida de manera rápida y sencilla. 
La aplicación brinda una experiencia interactiva donde el usuario puede visualizar productos, agregarlos a favoritos, administrar un carrito de compras y gestionar información de perfil.
Además, integra un asistente virtual inteligente que proporciona recomendaciones personalizadas de alimentos según las preferencias o consultas del usuario.
La aplicación está orientada principalmente a personas entre los 15 y 45 años, especialmente estudiantes y trabajadores que necesitan una solución rápida y práctica para decidir qué comer.

---

## Problema que resuelve

Muchas personas tienen dificultades para decidir rápidamente qué desean comer o buscan opciones organizadas que faciliten la selección de alimentos.

FoodieApp ayuda a resolver este problema mediante:

- Organización por categorías.
- Recomendaciones automáticas.
- Búsqueda rápida de productos.
- Interfaz intuitiva y amigable.

## Funcionalidades principales

###  Inicio de sesión y registro
Permite a los usuarios iniciar sesión o registrarse dentro de la aplicación.

###  Búsqueda de alimentos
Permite buscar productos de manera rápida mediante texto.

###  Filtro por categorías
El usuario puede visualizar alimentos organizados por categorías:

- Hamburguesas
- Pizzas
- Bebidas
- Comida rápida
- Otras categorías

###  Carrito de compras

Permite:

- Agregar productos
- Modificar cantidades
- Eliminar productos
- Calcular total de compra

###  Sistema de favoritos

Permite guardar productos favoritos para acceder posteriormente de manera rápida.

###  Perfil de usuario

El usuario puede:

- Ver información personal
- Visualizar carrito
- Consultar favoritos
- Cambiar foto de perfil usando cámara o galería

###  Chat Inteligente (IA)

Incluye un asistente virtual encargado de:

- Recomendar alimentos
- Sugerir bebidas
- Responder consultas del usuario

###  Diseño responsive

La aplicación se adapta a diferentes tamaños de pantalla.

## Instrucciones para instalar y ejecutar el proyecto

### 1. Clonar el repositorio

```bash
git clone https://github.com/BelaIsBelaG/FoodieApp.git
```

### 2. Entrar a la carpeta del proyecto

```bash
cd FoodieApp
```

### 3. Instalar dependencias

```bash
npm install
```

o

```bash
yarn install
```

### 4. Ejecutar el proyecto

```bash
npx expo start
```

o

```bash
npm start
```

### 5. Abrir la aplicación

Escanear el código QR utilizando:

- Expo Go (Android)
- Cámara (iOS)

o ejecutar en:

- Emulador Android
- Emulador iOS

### Descripción de carpetas

**assets/**
Contiene imágenes, iconos y recursos multimedia.

**components/**
Contiene componentes reutilizables de la aplicación.

**screens/**
Contiene las pantallas principales del sistema.

**navigation/**
Gestiona la navegación entre pantallas.

**context/**
Maneja estados globales mediante Context API.

**services/**
Contiene servicios y lógica adicional.

**styles/**
Archivos relacionados con estilos globales.

**utils/**
Funciones auxiliares reutilizables.
